Submission requirements

  • Register a developer account and pay its one-time registration fee. Verify contact email, enable 2-Step Verification, and complete any account-specific verification shown in the dashboard. Registration, Account setup, Policies.
  • Upload a ZIP with manifest.json at its root, bundled executable code, and an icon. Current project is MV3 and has no remote executable code. The current concept is wired into the manifest with toolbar and store icon sizes; final branding is still pending.
  • Supply a 128×128 PNG store icon and at least one actual product screenshot at 1280×800 or 640×400. The README screenshot is a 1280×800 capture with fictional tabs on a gray background. Small 440×280 and marquee 1400×560 promotional images are optional under the current live documentation. Image requirements.
  • Write accurate title, summary, description and category; describe one coherent purpose: a keyboard launcher for finding tabs and navigating to a selected destination. Do not imply Arc or OpenAI endorsement or promise history/autocomplete features we do not implement.
  • Publish a privacy policy, supply its URL, complete data-use disclosures and explain every permission. Explain local tab matching and explicit web-search/ChatGPT handoffs. Include Limited Use compliance. Dashboard privacy fields, User data policy.
  • Choose distribution and submit for review. Deferred publishing allows approval before going live. Approval is not guaranteed. Submission process.

Permission explanations for review

PermissionUse in current implementation
tabsRead titles, URLs and recent activity for local open-tab matching and switch to the selected tab.
activeTabTemporary access to the page explicitly invoked by the user.
scriptingInsert the tab picker on the invoked page; protected pages use a window.
storageKeep temporary picker session IDs and source-tab context in session storage. Remove obsolete debugging storage on upgrade.
searchSubmit only the user-selected query through the browser’s configured search engine.
faviconDisplay site icons through Chrome’s favicon endpoint.

The web-accessible palette declaration for all URLs is not a persistent host permission. The manifest requests no history permission or persistent host access.

Privacy wording to cover

Tab titles, URLs, and last-accessed data are processed locally for matching. There is no developer-operated telemetry, advertising or backend in the current code. Typed text is not sent while searching tabs. Selecting web search sends the query to the configured search provider. Selecting Ask ChatGPT opens the query in a ChatGPT URL, where OpenAI’s policies apply; the URL can remain in browser history. Do not claim that nothing ever leaves the browser. Final dashboard answers must match the public privacy policy and actual behavior.
