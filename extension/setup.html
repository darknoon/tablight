Set up your shortcut

Open Tablight with a shortcut or its toolbar icon.

  3. Press ⌘T, or choose another shortcut. Keep the scope set to In Dia or In Chrome, depending on your browser.

⌘T normally opens a new tab. Assigning it here uses it for Tablight instead. If your browser keeps intercepting it, choose another shortcut.

Try it

Return to a website and press your shortcut. Type to find a tab, use ↑ / ↓ to choose, then Return to switch. With no text, Return switches to your previous tab. Escape closes the picker.

Protected browser pages open the picker in a separate window. Web search and Ask ChatGPT send your text only when you select them.

You can reopen these instructions from the extension’s Options menu.
